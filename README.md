# PrepMate

PrepMate is a RAG-based AI study assistant.

### Current Stack

* Python
* ChromaDB
* Sentence Transformers
* PyPDF

### Current Pipeline

PDF → Text Extraction → Page-wise Chunks → Embeddings → ChromaDB

### Current Status

PDF ingestion and embedding storage pipeline completed.

### Next

Implement retrieval and connect the retrieved context to the LLM.


## Running Locally

Clone the repository, install the required dependencies, and run the application locally using the project's configured environment.
